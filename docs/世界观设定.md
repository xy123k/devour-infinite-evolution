# 《无限吞噬进化》世界观设定

---

## 一、核心设定

### 玩家身份
玩家是基因实验室中的实验体——被注入"无限吞噬基因"的原始细胞。设备故障后逃入城市，从吞噬现代生物开始，逐步觉醒基因深处的远古记忆，获得穿越时间的能力。

### 核心循环
```
吞噬生物 → 获取基因碎片 → 解锁天赋 → 变强 → 死亡
→ 属性转化为自由点 / 天赋转化为碎片
→ 局外永久成长 → 更强地轮回再战
```

### 最终真相
主角是所有生物的共同祖先，整个旅程是在重走自己曾经的进化之路。

---

## 二、时代递进（9大时代）

**设计逻辑**：不是从远古到现代，而是**从现代往回追溯**——玩家越变强，越能觉醒更古老的基因记忆，穿越到更远古的时代。最终到达"混沌轮回"，实现无限循环。


## 三、当前已实现的6张地图（原始海洋/生命登陆时代）

每张地图3层，最后一层Boss，打完自动切换下一张。

### 1. 原始浓汤
- **环境法则**：丰饶原液 — 治疗效果+30%，每回合回复3%最大生命
- **敌人特点**：噬菌体、草履虫等最原始生命
- **设计定位**：新手地图，法则偏治疗，降低上手难度

### 2. 潮汐滩涂
- **环境法则**：潮汐周期 — 速度+15%
- **敌人特点**：潮汐带生物，敏捷型
- **设计定位**：强调先手和闪避的地图

### 3. 珊瑚碎石带
- **环境法则**：珊瑚迷踪 — 受伤-15%命中，命中-10%
- **敌人特点**：珊瑚礁生物，防御型
- **设计定位**：命中率压力大，需要堆感知或带命中天赋

### 4. 温带林地面
- **环境法则**：落叶庇护 — 防御+20%，低血量时回复5%生命
- **敌人特点**：森林地表生物
- **设计定位**：苟活流友好，低血反打

### 5. 雨林地表
- **环境法则**：密林瘴气 — 攻击+10%，每回合损失2点生命
- **敌人特点**：雨林剧毒生物
- **设计定位**：Dot流主场，持续伤害加成

### 6. 东非草原
- **环境法则**：稀树烈日 — 攻击+15%，治疗效果-30%
- **敌人特点**：草原大型生物
- **设计定位**：纯输出地图，治疗被压制，速战速决

## 四、基因与天赋体系

### 天赋数量与品质
| 品质 | 数量 | 来源 |
|:--|:--:|------|
| 普通 | 30 | 普通敌人碎片 |
| 稀有 | 25 | 精英敌人碎片 |
| 史诗通用 | 10 | 精英概率掉落碎片 |
| 史诗Boss专属 | 34 | 区域Boss核心 |
| 传说 | 8 | 深层Boss核心 |
| 神话 | 10 | 混沌轮回Boss |
| 融合 | 15 | 双史诗Lv.5合成 |
| 无限成长 | 6 | 各品质分散 |
| **总计** | **138+** | |

### 天赋类型
| 类型 | 数值强度 | 说明 |
|:--|:--:|------|
| 纯被动 | 100%基准 | 常驻加成，无主动技能 |
| 被动+条件触发 | 85% | 被动较弱，条件触发额外效果 |
| 被动+主动技能 | 60-70% | 被动最弱，但提供主动技能 |

### 携带规则
- **被动槽**：无限。初始4个，后续天赋点递增解锁，所有已解锁天赋自动生效
- **主动槽**：最多6个。初始3个，25级4个，50级5个，精粹解锁6个
- 主动技能解锁后进入技能池，自由选带，不绑定被动
- 神话天赋无携带上限，阶段制解锁（三阶段）

### 死亡转化
- 已分配五维属性 + 未分配属性点 → 按50%转化为自由属性点（局外永久成长）
- 已装备/已解锁天赋 → 转化为碎片保留（100%保留）
- 层数保底：到达层数×0.5 额外自由属性点
- 所有碎片/核心/材料100%保留

## 五、核心设计原则

1. **无限成长不妥协** — 被动槽无上限，神话天赋无携带上限
2. **死亡不惩罚** — 所有碎片100%保留，属性按比例转化
3. **战斗快速** — 战斗内冷却，战斗结束重置，每场战斗独立
4. **碎片来源可追溯** — 每个天赋都有明确的敌人掉落来源
5. **溢出转化必亏** — 杜绝套利Build
6. **环境法则差异化** — 每张地图有独特规则，Build需调整
7. **控制有空窗期** — 不允许无限控制链
8. **快速狩猎** — 后期清杂兵可跳过，保留精力给Boss战
9. **敌人强度只与层数挂钩** — 不随轮回变强，让玩家感受成长
10. **智能补足弹窗** — 系统推荐合成，玩家确认执行

## 六、商业化设计（上架前需实装）
