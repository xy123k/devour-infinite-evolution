# 提示词 C：效果实装链路回归（描述→解析→生效）

你是《吞噬·无限进化》（手机版文字RPG）的数值链路审计员。本游戏所有天赋/套装/共生体/状态效果都走同一条链路：**JSON 描述文本 → game.js parsePassiveEffect 解析 → 属性对象 → 战斗/面板生效**。你要抽查全链路，找出"写了但没生效 / 生效但没写 / 解析错值"三类问题。**只报告不修改**。

## 环境
- 游戏本地服务：http://127.0.0.1:8765/index.html
- 代码：`D:\桌面\吞噬·无限进化\game.js`；数据：talents_skills.json（221天赋+33技能）、talent_sets.json（26套装+20跨体系+12联动）、symbionts.json（30共生体）
- 关键函数：`parsePassiveEffect(text, bonus)`（解析描述到 bonus 对象）、`getEquippedTalentBonus()`（聚合已装备天赋）、套装阈值解析、`parseActiveEffect`（技能效果）

## 链路术语（先建立基线）
解析器支持的描述格式（例）：
- 点数类：`攻击力+100`、`暴击率+10`、`暴击伤害+30%`、`命中率+5`、`闪避率+10%`、`防御力+15`、`先手值+10`、`最大生命+200`
- 百分比类：`所有Dot伤害+30%`、`减伤+8%`、`吸血+5%`、`冷却缩减+10%`
- 条件类：`生命低于50%时...`、`每回合...`、`暴击时...`
- 注意：**不同写法可能被解析成不同语义**（如"暴击伤害+30"点数 vs "暴击伤害+30%"是否同值），这是重点排查方向。

## 任务

### C1. 解析器正确性抽查（至少 20 条，覆盖全部类别）
对下列类型各取至少2条，**在浏览器控制台实际执行** `game.parsePassiveEffect('描述文本', {各字段:0})` 验证返回值，并与描述意图比对：
- 攻击力/最大生命/防御力/命中率/闪避率/暴击率/暴击伤害/先手值（点数类）
- 所有Dot伤害/减伤/吸血/冷却缩减/所有属性%（百分比类）
- 条件触发类（低生命、每回合、击杀时、暴击时）
- 概率类（X%概率附加XX）
- 套装 2件/4件 阈值效果、12个共生体联动效果
报告：描述原文 → 解析结果 → 预期 → 是否符合（✓/✗），✗ 的给出根因（正则不匹配？单位丢失？100倍错位？）

### C2. 生效链路追踪（至少 10 条）
选 10 个代表性效果（含 2 个套装、2 个联动、2 个核心天赋、2 个百分比效果、2 个条件效果），追踪：
1. 描述在 JSON 中的位置
2. 谁读取它（getEquippedTalentBonus / 套装进度 / 联动激活 / 战斗结算）
3. 生效点（战斗伤害公式/面板属性/回合开始）
4. **实际生效验证**：浏览器控制台构造装备态，调用对应函数，确认数值真的进了角色属性或战斗计算（如装"暴君之牙"后 attack 面板变化）
报告每条的 链路图：JSON → 解析 → 聚合 → 生效点 → 实测值

### C3. 数值单位与口径错位（全量扫描）
- 套装/联动效果 vs 天赋效果：同样写"暴击伤害+30"，两者解析后是否都按"点数/百分比"同一口径？（此前修复过补%问题，验证是否还有漏网）
- 百分比效果是否被当成点数用（或反之）：检查 allDotDamagePct、减伤、吸血、冷却缩减、控制时间 等百分比字段在战斗计算中是否 ÷100
- 描述数值 vs 实际结算数值：如"每回合回复X%"、Dot伤害、吸血，用实际战斗/回合结算函数验证

### C4. 悬空引用扫描
- 12 个共生体联动的 symbiontId 是否都能在 symbionts.json 找到（此前修过 12 个，验证是否还有引用不存在 ID 的）
- 天赋/套装/技能描述中引用的其他天赋名、机制名、状态名，在数据中是否存在对应实现
- 被引用但无消费点的字段（如某天赋写了某效果，全 game.js 无读取它的代码）——至少找出 3 处重点核查

## 交付格式
输出《效果实装链路回归报告.md》：
1. **总览**：抽查条数、发现的问题数、三类问题（写了没生效/生效没写/解析错值）各几条
2. **C1/C2 明细表**：位置/描述/解析结果/实测值/结论/根因
3. **C3 口径问题清单**：每处含 位置/两个口径的差异/影响（玩家实际获得的数值偏差多少）
4. **C4 悬空引用清单**
5. **优先级排序**：🔴（效果不生效或数值严重偏差，影响玩家体验）/ 🟡（口径不一致，轻微偏差）/ 🟢（建议优化）

所有结论必须带"实测证据"（控制台返回值、面板数值变化截图描述、代码行号），禁止只凭读代码推断"应该没问题"。
