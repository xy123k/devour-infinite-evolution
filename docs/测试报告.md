## 二、战斗后卡住问题（本次重点）

### 问题 1：战斗界面完全不显示（P0 严重）

- **状态**：✅ 已修复
- **问题现象**：点击"进入战斗"后，战斗逻辑正常启动（`inBattle=true`、敌人生成、日志追加），但**战斗界面全黑不可见**，只剩底部导航栏。
- **根因分析**：`index.html` 中 `#battleScreen` 的 inline 样式被 `fix_battle_layout.py` 改写为 `style="display:none;flex-direction:column;..."`。而屏幕显隐只靠 `.screen.active {display:block}` 类切换（`showScreen()` 仅增删 class，不碰 inline 样式）。**inline `display:none` 优先级高于类选择器**，导致 `.active` 类永远无法让战斗界面显示。
- **修复方案**（`index.html`）：
  1. 删除 `#battleScreen` 的 inline `display:none`；
  2. 新增 CSS 规则 `#battleScreen.screen.active {display:flex; flex-direction:column; height:100vh; padding:0; overflow:hidden;}`，保证激活时用 flex 纵向布局。
- **验证结果**：修复后重新进入战斗，`battleScreen` 计算样式为 `display:flex`，界面自然显示，无需任何 JS 注入。

### 问题 2：首次击杀时成就弹窗顶掉击杀奖励弹窗（P1 中高）

- **状态**：✅ 已修复
- **问题现象**：首次击杀后看不到"击杀奖励"弹窗，直接跳出"成就解锁"弹窗；击杀奖励被静默发放（奖励已入账，但玩家看不到内容）。
- **根因分析**：`victory()` 中两个定时器竞态——`setTimeout(400ms)` 弹出击杀奖励弹窗（z-index:10000），`checkAchievements()` 里的 `setTimeout(500ms)` 弹出成就弹窗；而 `showPopup()` 开头会调用 `closeKillDropPopup()`。于是 500ms 时成就弹窗把 400ms 时出现的击杀奖励弹窗**无感关闭**。
- **修复方案**（`game.js` `checkAchievements`）：成就弹窗改为轮询等待——若 `killDropPopup` 仍存在则每 300ms 重试，待玩家领取完击杀奖励后再展示成就。
- **验证结果**：后续击杀时奖励弹窗稳定常驻（等待 2 秒未被顶掉），点"确认领取"后正常返回主界面并继续探索。

### 问题 3（回归验证）：击杀奖励弹窗关闭后流程

- **状态**：✅ 通过
- 验证项：点击"确认领取"→ 弹窗关闭 → `mainScreen` 激活 → 探索前进按钮可用 → 连续 2 场战斗无卡死、无按钮残留禁用、控制台 0 错误。
